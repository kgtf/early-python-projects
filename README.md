# early-python-projects

This repository contains several Python projects I created before high school while learning programming.

These projects reflect my early experience with Python, GUI development, procedural graphics, image processing, file I/O, and object-oriented programming.

## Projects

### [Family Tree Generator](family-tree)

A Python application that lets users enter family members and generates a visual family tree in real time using Tkinter and Turtle Graphics.

### [Image-to-Text Converter](Image-To-Text)

A Python program that converts an image into a text-based representation by reading black-and-white pixel data and writing corresponding characters to a text file.



These projects are preserved here primarily to document my early programming experience and progression over time.
